PdfSnapOCR v2.3.0 · 2026-11-10

- App version/date are visible in the window title/footer and PDF metadata.
- Exported screenshot and import PDFs include a session timestamp in their filenames.
- Screenshot tab is compact; button explanations are hover tooltips, event details remain in the log or brief toasts.
- The screenshot preview restores the main window maximized after closing.
- A stopped PDF rasterization saves completed pages as an *_image_partial.pdf file and, when OCR is enabled, creates a matching *_ocr_partial.pdf.
- DPI choices: 96, 150, 200, 300, 400 and 600.
- Start with: python PdfSnapOCR.py
